# Diseño de Interfaces Web

Web personal de tres páginas diseñada primero en **Figma** y maquetada después con **HTML5 y CSS3**, sin frameworks.
Proyecto del módulo *Diseño de Interfaces Web* (2.º DAW, IES Tetuán de las Victorias).

🔗 **Demo:** https://dcesarsanchez.github.io/diseno-interfaces-web/

## Páginas

| Página | Contenido |
| --- | --- |
| `index.html` | Inicio: favicono personal (iniciales CS) y mi experiencia en DAW |
| `centro.html` | Información del IES Tetuán de las Victorias |
| `estudios.html` | Los módulos que estoy cursando |

## Tecnologías

- HTML5 semántico (`header`, `nav`, `main`)
- CSS3 (`estilos.css`)
- Figma para el diseño previo

## Cómo verlo en local

```bash
git clone git@github.com:dcesarsanchez/diseno-interfaces-web.git
cd diseno-interfaces-web
# abre index.html en el navegador, o usa la extensión Live Server de VS Code
```
